## C. XiangShanLab fork 与加密提交（提交指南第一、三、四、五步）

- [ ] **C1 fork 已存在且与上游同步**：打开 `https://github.com/<你的用户名>/XiangShanLab`；若页面提示落后于 `OpenXiangShan/XiangShanLab`，先点 Sync fork（避免 PR 冲突）。
- [ ] **C2 克隆 fork 到本地**（提交指南 1.3）：
  ```bash

  cd XiangShanLab/2026-CIE-RISC-V-Contest-Application-Track
  ls        # 确认 submit.sh 存在
  ```

- [ ] **C3 先读一遍 `submit.sh`**，确认三件事（已核对，结论见下方说明与 C6）：① 它要求的字段与格式；② 生成的 `submission.asc` 放在哪个目录；③ 是否会删除或忽略明文 `my_submission.txt`。

- [ ] **C4 创建 `my_submission.txt`**（提交指南 3.1–3.3），UTF-8 编码、扩展名 `.txt`，格式严格按提交指南：
