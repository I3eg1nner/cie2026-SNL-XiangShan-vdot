## 主结论口径

MinimalConfig 全核实测 latency 加速比：单次 16 元素点积 1.70×（函数整体，52 → 30.5 拍），长向量稳态 1.81×（单累加器，12.64 → 7.00 拍/迭代）/ 2.25×（2 累加器，12.64 → 5.63 拍/迭代）；1.70× 与 2.25× 未达建模值（2.00× / 3.00×）。出处 `README.md` §1.2、`docs/stage3/22_基线实现与延迟加速分析.md` §5.5、`bench/results/speedup.csv`、`bench/results/cycles_fullcore.csv`。

## 本地复核

```sh
cd submission/upload && sha256sum -c SHA256SUMS
```

`submission/upload/` 下散放的三册 PDF 与 PPT 的 PDF 与 `SNL-XiangShan-vdot-3-docs.zip` 内的完全相同（见 `SHA256SUMS`）；各包均远小于 500 MB。
文档、证据或视频有改动时：先提交到仓库，按「三册 PDF → PPT / 视频 → 四个包」的顺序重新生成，再提交新的清单与 `SHA256SUMS`。
